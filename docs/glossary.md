# Glossary

Product vocabulary mapped to code. Requests often arrive in Linktree's
words; translate them here before searching the codebase.

## Reference product

Linktree is the product Rinku follows. When comparing behavior, check what
Linktree does first: it is the reference implementation, not a rival.
Feature decisions that came from it are recorded below next to the term.

## Terms

| Word                          | Means in Rinku                                                                                                                                                                                                                                    | Lives                                                                                                                                                            |
| ----------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Layout (Linktree)             | The page header: how avatar, name, and banner compose. The field is `headerStyle`; the six recipes are classic, hero, banner, cutout, minimal, statement.                                                                                         | `headerStyleIds` in `lib/profiles/schema.ts`, picker in `components/appearance/appearance-header-section.tsx`, render in `components/profile/profile-header.tsx` |
| Section                       | One row on the public page: a link, a heading, or an embed.                                                                                                                                                                                       | `lib/db/schema/links.ts`, `lib/links/model.ts`                                                                                                                   |
| Section heading               | A non-link row that groups the sections under it (`kind: "heading"`, no URL, never clickable).                                                                                                                                                    | `createSectionHeading` in `app/actions/links/link.ts`                                                                                                            |
| Page alignment                | Whether the public page's content column reads center or left.                                                                                                                                                                                    | `pageAlignment` in `lib/profiles/appearance-options.ts`                                                                                                          |
| Wallpaper, background         | The page background: fill, gradient, blur, pattern, image, or video. One media row renders at a time.                                                                                                                                             | `wallpaperKind` in `lib/profiles/appearance-options.ts`, render in `components/appearance/wallpaper-layer.tsx`                                                   |
| Button style, corners, shadow | The link button recipe: variant (fill, outline, soft, glass), contour (sharp, soft, round, pill), umbra (none, soft, lift, hard).                                                                                                                 | `lib/profiles/appearance-buttons.ts`                                                                                                                             |
| Theme                         | One of 16 preset palettes, or `custom` once anything is tweaked. Applying a theme never deletes uploaded media and never moves the header recipe.                                                                                                 | `lib/profiles/appearance-presets.ts`                                                                                                                             |
| Save mode                     | Auto publishes every edit; manual keeps a draft until Publish. Set per editor area.                                                                                                                                                               | `app/actions/profiles/editor-settings.ts`, drafts in `app/actions/profiles/drafts.ts`                                                                            |
| @username display             | Visual text under the display name only. Hiding it is a render flag (`showUsername`), never a data or URL change: the page URL and search results keep the handle either way (decided against Linktree's behavior of showing nothing by default). | `showUsername` gate in `components/profile/profile-header.tsx`                                                                                                   |
| Insights                      | The 30-day visits, clicks, and click-rate dashboard.                                                                                                                                                                                              | `app/(protected)/[username]/insights/`                                                                                                                           |
| Age gate                      | A per-link minimum-age consent, proven by a signed cookie so visitors cannot mint unlocks.                                                                                                                                                        | `lib/links/age-gate.ts`, consent page in `app/go/[id]/route.ts`                                                                                                  |
